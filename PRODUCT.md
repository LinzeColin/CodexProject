# Product

## Register

product

## Users

Memory Atlas is used by Linze and future Codex/agent maintainers who need to recover project context, inspect derived memory evidence, and decide the next action without reading raw transcripts first.

## Product Purpose

Memory Atlas turns OpenAIDatabase data into a Chinese-first decision workspace. Success means the first screen explains what changed, what matters, what needs review, and what should happen next while preserving raw-data, proposal, and GitHub delivery boundaries.

## Brand Personality

Evidence-led, restrained, operational.

## Anti-references

Do not make the default experience a galaxy demo, schema browser, hash/path wall, marketing landing page, decorative card grid, or multi-layer reading ladder. Machine fields belong behind folded or secondary details unless a workflow explicitly needs them.

## Design Principles

- Answer the human question first: what changed, why it matters, what to do next.
- Keep Chinese as the default interface language; keep code, API, and schema terms only where they help verification.
- Prefer dense but readable operational layouts over decorative hero sections.
- Treat proposal and raw-data boundaries as visible product behavior, not hidden implementation notes.
- Make evidence and rollback paths easy to find before suggesting action.

## Accessibility & Inclusion

Target a readable product UI with strong contrast, keyboard-accessible controls, reduced-motion-safe behavior, and no reliance on color alone for state. Empty, error, and blocked states must explain the next action in Chinese.
