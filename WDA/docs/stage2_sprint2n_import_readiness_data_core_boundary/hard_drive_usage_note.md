# Hard Drive Usage Note

Sprint 2N does not need the external hard drive.

Forbidden for Sprint 2N:

- do not access `/Volumes/My Passport`
- do not access `/Volumes/WDA_WECHAT_APFS`
- do not mount APFS sparseimages
- do not scan WeChat source directories
- do not run exporter tools

All Sprint 2N validation uses the existing local Raw Import Pack under
WDA_MetaData.
