# Frontend Pages Spec

## Implemented Pages

- `/`: Chinese dashboard.
- `/system`: system status page.
- `/reports/{report_id}`: report reader page for local report sources.

## Dashboard Requirements

The dashboard prioritizes:

- Action Center
- Risk Center
- Opportunity Center
- Contact Radar
- Work Handoff
- Personal Behavior Optimization
- freshness and update status

It deliberately keeps technical row counts below the decision entrances.

## Visual Direction

This is product UI, not a landing page. The interface uses a restrained palette, familiar side navigation, stable cards, visible focus states, and Chinese-first labels.

## Current Gap

R3 P1 exposes report pages as readable local Markdown views. R3 P2 should improve detail-page hierarchy, responsive QA, richer evidence drill-down, and polished loading/error states.
