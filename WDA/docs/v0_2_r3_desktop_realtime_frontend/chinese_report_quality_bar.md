# Chinese Report Quality Bar

R3 P1 wires report navigation and local report serving. R3 P2 must raise report quality before final product-grade closeout.

## Required Report Structure

Each user-facing report should make these sections obvious:

- 结论
- 关键发现
- 为什么重要
- 证据
- 对我的影响
- 下一步
- 不确定的地方

## Quality Rules

- Use Chinese that a real owner can act on.
- Do not lead with raw tables or schema details.
- Every meaningful recommendation must link to evidence.
- Separate risks, opportunities, todos, handoff items, and behavior reflections.
- Mark uncertainty instead of inventing certainty.
- Keep private report content in `WDA_MetaData`, not Git.

## Current Gap

The current R3 P1 frontend links and serves existing v0.2-R2 report content. R3 P2 must rewrite and rank reports into a stronger product experience rather than merely wrapping old Markdown.
