# Hard Drive Usage Note

Sprint 2L does not need the external hard drive.

Do not access:

- `/Volumes/My Passport`
- `/Volumes/WDA_WECHAT_APFS`
- old-computer APFS sparseimage sources
- old-computer raw WeChat source directories

Sprint 2M also should not need the external hard drive if it runs against the
old computer's live WeChat environment and writes bounded export outputs under
WDA_MetaData.
