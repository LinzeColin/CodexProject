## 功能

1. 根入口压缩：`AGENTS.md` 只保留 always-on 铁律并硬限制 `<=4096 bytes`；README 只保留中文稳定导航、active/retired 入口、canonical boundary 与最小命令。
2. Registry 收敛：active/retired/migrated ID 与 path 全局唯一；移除 required project 的隐式 changed-scope exclusions；migrated path 不得重新出现。
3. Machine-readable cleanliness budget：声明入口字节/文件数、root item owner/purpose、active project entrypoint、AGENTS 必备 token 和 README 临时状态禁用模式。
4. Fail-closed auditor：以 Git candidate paths、registry 与 policy 计算 root ownership、入口可达、README parity、本地链接、安全路径和预算；输出稳定 JSON 与 SHA-256。
5. 自动化 gate：Project Governance CI 在大对象 hygiene 后执行 root cleanliness audit；任何错误返回非零。
6. 文档去重：AGENTS/README 不再复制迁出项目状态表；完整迁移事实只由 `governance/projects.yaml` 管理。

## 操作入口

```bash
python3 -B scripts/root_cleanliness_audit.py --root . --json
python3 -B -m unittest tests.governance.test_root_cleanliness -v
```

## 验收硬门

- `AGENTS<=4096 bytes`；README 无短期执行状态。
- root `unowned_item_count=0`；`broken_local_link_count=0`。
- active project registry/table 完全一致，入口齐全，duplicate ID/path=0。
- unapproved active scope exclusion=0；migrated path present=0。
- policy/schema 可解析，auditor 与 README generator 回归测试通过。

## 不包含

- 不修改项目业务、private/raw data、runtime、secrets、历史 Git object 或远端 refs。
- 不执行 history rewrite、force-push、PR/Issue 创建、提前 GitHub publication 或最终 cache/storage cleanup。
