## 最高优先级差距

1. **真实运行时缺失**：v0.1.4 App 仅打开静态 HTML，没有可构建产品源、后端 API、数据库绑定或真实持久化。
2. **准确性未闭环**：整数分与零差异工具可复用，但真实黄金数据仍未完成全量零分差异证明。
3. **公开仓库政策冲突**：R007 当前 Git 内容安全，但旧策略允许 owner 授权上传 raw/plaintext；v2.0 明确禁止任何此类例外，必须在 S03 废止。
4. **用户流程缺失**：导入、确认、失效、重算、刷新、恢复、报告和通知没有真实端到端链路。
5. **旧 UI 不可继承验收状态**：静态导航、按钮、表格、Q4/D/NO_GO 等技术表达只能作历史参考，不能证明产品能力。
